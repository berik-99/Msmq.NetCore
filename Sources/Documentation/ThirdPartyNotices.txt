Changes: extracted IntelliSense summaries, parameter/value/return descriptions
and exceptions; mapped assembly and namespace names; excluded unavailable
installer/designer APIs and obsolete CAS security claims; added compatibility
and platform notes for .NET Core and modern .NET.

The external XML is checked into the repository and copied beside the assembly.
Builds do not download Microsoft documentation or require .NET Framework.
To regenerate it from the pinned source, run:

    python tools/update_api_docs.py

Regeneration requires Python 3.9+ and network access. This is a maintenance
operation, not a build prerequisite. This port is not endorsed by Microsoft.
